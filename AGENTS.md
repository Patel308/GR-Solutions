## Google Search Console data

When asked for "console data", GSC, Search Console, rankings, clicks/impressions, queries, or
index status for grsolution.co.in, use `search-console/` (read `search-console/README.md` first).
Run `py search-console/gsc.py <command>`. The site is preset to `grsolution` (property `sc-domain:grsolution.co.in`).
Auth is a central read-only service account, so don't write new GSC/OAuth code or ask for credentials.
